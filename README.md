# Hotel Management System 🏨

A comprehensive desktop application designed to streamline hotel operations, including room bookings, customer records, and billing system management.

## 🚀 Features
- **User-Friendly UI:** Desktop interface built using Java Swing and AWT.
- **Database Management:** Secure storage for customer data and room availability using MySQL.
- **Connectivity:** Real-time backend connectivity using JDBC drivers.
- **Core Modules:** Automated calculation for check-in/check-out and billing tracking.

## 🛠️ Tech Stack
- **Frontend/UI:** Java (Swing, AWT)
- **Backend:** Java (Core, JDBC)
- **Database:** MySQL
- **IDE Tools:** Apache NetBeans / VS Code

## 📋 Prerequisites & Installation
1. Install Java JDK 8 or higher.
2. Setup MySQL Database and import the database file.
3. Open the project in NetBeans/VS Code and configure the JDBC connection string.
4. Run the application.
